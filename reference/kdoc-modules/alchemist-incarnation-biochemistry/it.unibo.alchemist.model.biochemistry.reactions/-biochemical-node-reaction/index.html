BiochemicalNodeReaction

class BiochemicalNodeReaction(node: Node<Double>, timeDistribution: TimeDistribution<Double>, environment: Environment<Double, *>, randomGenerator: RandomGenerator) : ChemicalNodeReaction<Double> (source)

A memoryless biochemical reaction with an explicit contract for its supported condition semantics. Every factor is validated even when an earlier factor has already made the total rate zero.
