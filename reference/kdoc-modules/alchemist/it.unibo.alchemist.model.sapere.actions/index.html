class LsaAllNeighborsAction(randomGenerator: RandomGenerator?, environment: Environment<List<ILsaMolecule>, *>, reaction: NodeReaction<List<ILsaMolecule>>, molecule: ILsaMolecule) : LsaRandomNeighborAction

Adds the LSA molecule to all the valid neighbors. The molecule can be different from a neighbor to the other, because some special variables (e.g., #D) are specific for each node: N molecules are instanced if there are N neighbors. The randomGenerator is unused, and can be null.

class SAPEREMoveLSAToAgent(reaction: NodeReaction<List<ILsaMolecule>>, destination: ILsaNode, template: ILsaMolecule) : AbstractSAPEREAgent

Matches template, removes a single instance of it from the current node, and moves it to destination. Since the destination could be anywhere in the system, this action may trigger a large number of updates, slowing down the whole simulation. Handle with care.
