ObservableMutableSet

class ObservableMutableSet<T>(initial: Iterable<T> = emptyList()) : AbstractObservable<Set<T>> , ObservableSet<T>

A mutable observable set implementation, which allows for observing changes to the set and provides notifications when its contents are modified. This class supports addition, removal, and observation of modifications to the set.
