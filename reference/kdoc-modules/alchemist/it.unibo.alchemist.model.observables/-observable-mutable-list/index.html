ObservableMutableList

class ObservableMutableList<T> @JvmOverloads constructor(initial: Iterable<T> = emptyList()) : AbstractObservable<List<T>> , ObservableList<T>

A mutable observable list implementation, which allows for observing changes to the list and provides notifications when its contents are modified. This class supports addition, removal, updates, and observation of modifications to the list.
