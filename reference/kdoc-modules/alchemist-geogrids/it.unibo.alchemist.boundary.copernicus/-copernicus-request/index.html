CopernicusRequest

data class CopernicusRequest(val endpoint: String, val dataset: String, val inputs: Map<String, Any>) : CachedDirectoryKey(source)

A request of data to a Copernicus data store.

Throws

IllegalArgumentException

if endpoint is not https://<store>.copernicus.eu/api or 127.0.0.1, or has a query, a fragment, or user information; or if dataset is not made of letters, digits, ., _, and -, starting with a letter or a digit; or if inputs hold keys that are not strings, or values with no JSON equivalent (anything but null, booleans, numbers, strings, maps, iterables, and arrays).
