CacheableDataLoader

fun interface CacheableDataLoader<in K : CachedDirectoryKey>

Produces the content of a LoadingDirectoryCache entry: given a key, it fills a directory with files that are ready to be opened, for instance by downloading them or by computing them locally. The cache is unaware of how the data is obtained.

interface CachedDirectoryKey

Identity of a LoadingDirectoryCache entry: equal keys denote the same data, and thus the same directory.

class FileSystemDirectoryCache<in K : CachedDirectoryKey>(loader: CacheableDataLoader<K>, root: Path) : LoadingDirectoryCache<K>

A LoadingDirectoryCache storing its entries as directories under a common root on the local file system, loading the missing ones through a CacheableDataLoader. It knows nothing about how data is obtained, depending only on CachedDirectoryKey.

fun interface LoadingDirectoryCache<in K : CachedDirectoryKey>

A cache of directories, each one identified by a CachedDirectoryKey, that loads missing entries on access, in the spirit of a LoadingCache.
