AbstractObservable

abstract class AbstractObservable<T>(emitOnDistinct: Boolean = true) : Observable<T>

The base implementation of Observable: it keeps the registered callbacks, hands out their handles, and notifies them of the values published through updateAndNotify.

Observables holding their own state publish it whenever it changes. Observables derived from other sources compute their value through computeFresh, and observe their sources, through observeSource, only while they are observed.

Parameters

emitOnDistinct

whether to emit only when the new derived value is different from the current one. If so, the first registration computes the current value even when not delivering it, so that the first emission can be compared against it; otherwise, a registration that does not deliver the current value computes nothing.
