AbstractEngine

abstract class AbstractEngine<T, P : Position<out P>>(val environment: Environment<T, P>) : Simulation<T, P>

Abstract base class for simulation engines, providing common functionality for status management, time tracking, command scheduling, and output monitoring.

reactionAdded
Link copied to clipboard
abstract fun reactionAdded(reactionToAdd: Reaction<T>)

Notifies the simulation that a reaction host has registered reactionToAdd. Model code should register the reaction through its host; the host invokes this callback after membership actually changes. Adding a node invokes this callback once for each reaction already hosted by that node; node and topology changes have no separate simulation callback.

reactionInvalidated
Link copied to clipboard
abstract fun reactionInvalidated(reactionToUpdate: Reaction<T>)

Marks reactionToUpdate as a reaction whose observed scheduling inputs changed. The notification is synchronous and must originate on the simulation thread. The engine refreshes each affected reaction once when the enclosing model mutation completes.

abstract fun reactionRemoved(reactionToRemove: Reaction<T>)

Notifies the simulation that a reaction host has unregistered reactionToRemove. Model code should unregister the reaction through its host; the host invokes this callback after membership actually changes. Removing a node invokes this callback once for each hosted reaction before disposing it.
