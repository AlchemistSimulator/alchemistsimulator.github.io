LsaAscendingGradientDist

class LsaAscendingGradientDist<P : Position<P>>(environment: Environment<List<ILsaMolecule>, P>, reaction: NodeReaction<List<ILsaMolecule>>) : AbstractSAPERENeighborAgent<P>

Moves the response LSA to the last neighbor found with a lower gradient distance, adding the distance to that neighbor to the distance carried by the response.
